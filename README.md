# SMART-STUDY-PLANNER
A simple Python-based Smart Study Planner to manage study tasks, set priorities and deadlines, mark tasks as completed, and track overall study progress.

##  Project Overview

**Smart Study Planner** is a simple Python-based project designed to help students organize and manage their study tasks. It allows users to add study topics, set priorities and deadlines, complete tasks, delete tasks, and track their overall study progress.

This project is developed using basic Python programming concepts, making it suitable for beginners and first-year students.

## Objective

The main objective of the **Smart Study Planner** is to make study planning easier and more organized.

- Organize their study tasks
- Set priorities for different topics
- Keep track of deadlines
- Mark completed tasks
- Monitor their study progress
- Identify high-priority pending tasks

##  Features

-  **Add Study Task**  
  Add a subject, topic/chapter, priority, and deadline.

  - **View Study Tasks**  
  View all added study tasks and their current status.

- **Complete Task**  
  Mark a study task as completed.

-  **Delete Task**  
  Remove a task from the study planner.

  - **Study Progress**  
  Display total tasks, completed tasks, pending tasks, and completion percentage.

 - **High Priority Tasks**  
  Display pending tasks marked as high priority.

  - **Simple Command-Line Interface**  
  The project runs directly in the Python terminal without requiring external libraries.

## Installation and Setup

### 1. Install Python

Download and install Python from the official Python website:

https://www.python.org/downloads/

Make sure Python is added to your system PATH during installation.

### 2. Install VS Code

Download and install Visual Studio Code:

https://code.visualstudio.com/

### 3. Clone the Repository

Open the terminal and run:

```bash
https://github.com/shahreet119-web/SMART-STUDY-PLANNER/tree/main
```

Then open the project folder in VS Code.

### 4. Run the Project

Open the terminal in VS Code and run:

python main.py

The Smart Study Planner will start in the terminal.
